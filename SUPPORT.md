| You want to… | Go to |
|---|---|
| Read how something works | the [wiki](https://extrutex.github.io/ananas-slicer-wiki/) (English and German) |
| Ask a question, show a print, discuss an idea | [GitHub Discussions](https://github.com/Extrutex/ananas-slicer/discussions) |
| Report a bug or a crash | [Issues](https://github.com/Extrutex/ananas-slicer/issues/new/choose), pick the matching form |

| Report a security problem | [SECURITY.md](SECURITY.md), privately |
| Support the project | [Ko-fi](https://ko-fi.com/3dw_sebastianwindt) |

## Before you ask

Please have these at hand; every report needs them:

- the ANANAS SLICER version (`Help` → `About ANANAS SLICER`),
- your operating system and how you installed (installer, portable, DMG, AppImage, built from source),
- your printer and its kinematics, and your Klipper and Moonraker versions,
- the project file (`.3mf`) if the problem shows in a slice,
- the log of the session. Logs live in the `log` folder of the settings directory:
  `%APPDATA%\AnanasSlicer` on Windows, `~/Library/Application Support/AnanasSlicer`
  on macOS, `~/.config/AnanasSlicer` on Linux.

ANANAS SLICER is alpha software with a single maintainer. Response times vary;
clear reports with files get answered first.
